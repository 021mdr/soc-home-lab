# SOC Home Lab — Investigations

Домашняя SOC-лаборатория для отработки навыков аналитика (L1): сбор логов,
обнаружение, триаж алертов и написание отчётов об инцидентах.

> Все атаки проводились в изолированной виртуальной сети на моём оборудовании,
> в учебных целях.

## Схема стенда

```
Kali (атакующий) ──► Windows Server 2022 (цель)
                             │
                   Windows Event Log + Sysmon
                             │
                       агент Wazuh
                             │
                             ▼
                    Wazuh SIEM ──► дашборд (триаж алертов)
```

| Машина          | Роль              | ОС                        |
|-----------------|-------------------|---------------------------|
| Wazuh           | SIEM              | Ubuntu Server 24.04       |
| Windows Server  | Цель мониторинга  | Windows Server 2022       |
| Kali            | Атакующий         | Kali Linux                |

Сеть: изолированная, NAT. IP-адреса стенда внутренние (192.168.x.x).

## Инструменты

- **Wazuh 4.14** — SIEM: сбор логов, корреляция, алерты.
- **Sysmon** (конфиг SwiftOnSecurity) — расширенные логи процессов и сети.
- **Windows Event Log** — события входа (4624 / 4625).
- **MITRE ATT&CK** — классификация техник.
