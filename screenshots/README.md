# Скриншоты

Скриншоты из Wazuh и с машин стенда, которые подтверждают расследования.

**Кейс 01 — ложное срабатывание:**
- `01-sysmon-cluster.png` — группа алертов после перезагрузки, включая 92213 (уровень 15)

**Кейс 02 — подбор пароля (brute force):**
- `02-attack-4625.png` — серия событий 60122 (Logon Failure) и анонимный логон 92652
- `02-event-fields.png` — поля события 4625: ipAddress, logonType 3, subStatus 0xC000006A
- `02-lockout.png` — событие 60115 / 4740 (блокировка учётной записи после включения защиты)

Внутренние адреса стенда (192.168.x.x) оставлены намеренно; паролей на скриншотах нет.
